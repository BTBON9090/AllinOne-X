# 中文姓名示例库

基础填充的“姓名 → 中文”使用 512 个整理过的完整姓名。数据源是
`shared/chinese-names.js`，Figma 与 MasterGo 共用同一份库。

姓名由常见单姓或复姓，加一字或二字名字组成；完整姓名有二、三、四字，
包含有意保留的可爱叠字名。每项都保存完整姓名，不从零散汉字重新拼接。

## 数量与风格

- 男、女样本各 256 个；这些分组表达示例人物的设计意图，也包含中性姓名。
- 二字姓名 127 个，三字姓名 321 个，四字姓名 64 个。
- 16 种风格，每种 32 个姓名，男女各 16 个。

## 填充方式

每轮将男女样本分别打乱，再交替抽取；512 个姓名在一轮内各使用一次，
用完后重新打乱。选择“英文”时继续使用英文姓名生成方式，中英同时选中时
继续混合两种语言。现有前缀、后缀功能同样适用于新姓名。

## 维护与检查

修改姓名库后运行 `npm run check:chinese-names`，检查数量、重复姓名、
风格覆盖、姓名结构、长度分布以及抽取循环。浏览器回归还会实际点击姓名
填充按钮，确认发送到宿主的是库中的完整姓名，并检查英文分支。

保持完整姓名人工整理；新增样本时，同时检查姓与名的搭配、读音、
重复字及整体气质。上述风格用于示例内容的组织，不表示互斥分类。

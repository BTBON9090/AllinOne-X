# 4.4.0 图层工作流

## 超级选择

| 范围 | 查询对象 |
|---|---|
| 全页 | 当前页面全部后代，包含实例内部和隐藏图层 |
| 子孙 | 选中对象自身及全部后代 |
| 内在 | 选中容器全部后代，排除所有选中根对象 |
| 子级 | 选中对象的直接子级 |
| 同级 | 每个选中对象所在父级的子节点，排除全部选中对象 |

非全页范围需要选中起点。查找并选中结果后切换范围/筛选，继续使用原起点；用户在画布主动更改选择后才更新起点。重叠范围按节点 ID 去重。

每组多选为 OR；类型、状态、名称及高级属性组之间为 AND。排除表示“该组一个也不能命中”；空组不限制。隐藏与锁定包含父层继承，Auto Layout 支持组件与实例，Slot 按原生类型或 slotContentId 引用识别，不按名称猜测。

## 组件构建

普通构建有单个组件、多个组件、组件集三种。截图中的错误来自转换后读取失效 Frame 的 parent。当前实现先保存父级，在副本上转换和合并，所有分组成功才删除原 Frame；失败清理副本。选区包含相互嵌套的 Frame 时先报错，避免重复转换同一子树。

AI 构建步骤：

1. 读取每个 Frame 的完整图层树、路径、类型、文本、可见性、尺寸和可用样式信息。
2. 可选导出每个 Frame 的截图；先验证当前模型能读取测试图片。
3. AI 给出分组、组件/组件集名称、各变体属性和值，以及 TEXT、BOOLEAN、INSTANCE_SWAP、SLOT 的建议和绑定路径。
4. 在插件里显示读取数量、方案与建议。点击“按方案构建”才修改画布。
5. 应用前检查快照是否过期，拒绝未知 ID、缺失 Frame、重复变体组合、重复属性和无效绑定。宿主不支持的原生属性明确列入警告，不伪装成创建成功。

构建内的语言组件集已移除。组件清洗的“AI 名称翻译”将选中组件/组件集名称译为英文，保留变体结构与真实属性 ID。

## 查重和命名

- 分段匹配：按连字符、下划线、空格、点和斜杠切词，比较完整词段。`cart` 不会作为词段匹配 `cartography`。
- 子串匹配：比较连续字符片段，上述名称可能命中，适合更宽松的粗筛。
- AI 语义精筛：依据名称过滤语义不同的误匹配，不读取图片；改为 Switch。
- AI 视觉查重：独立于名称候选对，移除通用词后导出两侧图层，以精确节点 ID 比较截图。只给出相同/相似建议和原因，不删除图层；结果行可定位两侧。需选择互不嵌套的容器。
- 图层命名：根据截图建议用途名称，允许编辑、勾选后应用。默认一个通用名；多含义模式最多六个相关词组，使用 `、` 分隔，避免 `/` 创建资产层级。
- 不使用 AI 时，可用普通编号命名、原有名称查重与手工组件构建。

“清理名称中的 ID 后缀”只移除显示名称末尾的 `#123:456`。真实属性 ID 仍由宿主管理，用于属性/实例引用，不会删除。

## 性能和失败处理

| 操作 | 单次上限 / 分批 |
|---|---|
| AI 组件方案 | 30 个 Frame；最多 5,000 个内部图层 |
| 图层命名 / 名称翻译 | 50 个对象；命名每批 8 个，翻译每批 15 个 |
| 视觉查重 | 两侧合计 60 个候选图层；每侧每批 6 个，最多 2 个并发请求 |
| 图层树 | 合计 5,000 层，序列化结构最多 1.5 MB；超限报错，不默默截断 |
| 图片 | 最长边 384 px，不放大小图；UI 压缩 JPEG 0.78；原始图片总量最多 6 MB |

读取逐项让出事件循环并显示进度；分析可取消，迟到响应不应用。每个模型配置首次使用图像前，发送生成的四位数字测试图片，验证服务确实读取图像。内置文本代理及已知文本模型直接提示更换设置。网络失败、截图失败与部分批次失败会反馈，普通功能不依赖识图能力。

应用阶段不提供会误导用户的中途取消按钮；已成功修改可使用宿主撤销。快照只留在当前插件内存中，最多保留八次读取记录。

## CompKit

矩阵排列与说明书共用一页，底部“生成说明书”开关默认关闭。每个属性分配为列、行或分组，单轴支持多个属性。AI 可以读取结构并建议这些分配；用户仍可手动调整。

共享布局算法覆盖普通矩阵、单个说明书和批量目录。每列/行按该列/行最大尺寸计算，剩余属性分组，重复组合用额外位置显示，不覆盖。无 Y 轴时仍正确累加分组高度。

- 横纵间距：单元格边缘之间的间距；较小节点对齐单元格左上角。
- 组件集内边距：组件集边界到矩阵单元格的距离。
- 说明书外边距：说明书边界到内容区域的距离。
- 区域间距：说明书内容块之间的间隔。
- 分组间距：矩阵不同属性分组之间的间隔。

去掉矩阵舞台额外硬编码的 24 px 内边距和隐式居中偏移。关闭圆角时会重置旧圆角。输入按控件边界规范化并回写显示值，零值有效。编辑目录中的一个组件集会保留同目录其他组件集。

## 验证与限制

已执行双平台构建、UI 语法、等价检查、智能填充/序列/本地化/窗口回归，以及以下行为测试：

- `npm run check:layer-workflows`：20 组范围与包含/排除组合、继承状态、Slot、多维矩阵、双宿主事务回滚和过期快照。
- `npm run check:layer-ui`：Chrome 440/340 px 交互，前后缀、实时尺寸按钮、五张信标、名称预览应用、AI 请求与方案预览、识图测试、JPEG 请求、无视觉模型回退和多属性矩阵。
- 既有 workspace、window-bookmarks、localization 浏览器套件：15 个导航、三种窗口尺寸、键盘与拖拽、中文/英文及主题。

AI 网络响应和画布 API 使用测试替身验证；未使用用户的模型凭据、真实 Figma/MasterGo 文档做端到端运行。原生 Slot 写入及宿主布局渲染仍需在实际宿主中验证。MasterGo 当前无原生 Slot 创建适配时会保留容器并报告具体属性警告。

API 依据：[Figma 组件属性与 Slot](https://developers.figma.com/docs/plugins/working-with-component-properties/)、[DeepSeek 视觉输入](https://api-docs.deepseek.com/guides/vision/)。模型不靠名称猜测是否支持图片，未知模型使用实际能力测试。

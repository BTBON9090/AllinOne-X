# All in One for Figma

这是 AllinoneX 4.4.6 的 Figma 实现，与同仓库 `../mastergo/` 版本同步维护。

4.4.6 内置组件族整合 skill，按“观察差异、规划统一属性、整合”三阶段处理；支持多组件集创建整合副本，保留原集与已有实例关联。4.4.5 修复重复变体组合导致分析反复停在 80/150：草稿先保存并继续，最终统筹仍无法区分的对象全部保留为独立组件，保持原有外观。4.4.4 新增截断自动缩批、子批次进度保存与恢复，启动问候不再自动请求 AI。4.4.3 统一为每批最多 20 张、逐批暂存、最终 AI 统筹后再应用；正常自动继续，中断手动续传。统筹失败只重试统筹，不重传已分析图片。4.4.2 改为根对象截图分析、限流时保留进度，并增加标题定位。Figma 可继续补入已有组件集；MasterGo 未开放对应 API 时保留为独立组件并提示。4.4.1 增加 800 目标分批分析、外观保护、请求限流重试与紧凑 AI 控件。4.4.0 新增 AI 组件方案、图层命名、组件名称翻译和视觉查重；支持多属性矩阵、原生 Slot 查找与前后缀同时填充。移除组件构建中的语言模式和精简侧栏入口，收起气泡保留。完整行为与测试范围见 [图层工作流](../docs/LAYER_WORKFLOWS.md)。


4.2.1 修复智能填充的混合字体加载和选区一致性，统一 Tabler 线性图标与紧凑样式，隔离侧栏和内容区滚动。精简模式会将窗口缩小到 360 × 520。

## 主要能力

- 简易工具、超级选择、智能填充、文字工具、尺寸助手、PPT、组件清洗、Jumpback、等轴形变、语言切换、CompKit 与跨画板查重。
- 实例逆向母版：从所选实例的当前状态创建新的本地母版，原实例保持不变；本地组件集最多完整还原 100 个真实变体。
- 组件构建器：把一个或多个 Frame 创建为单个组件、多个组件、普通组件集；也可先使用 AI 分析分组与属性，可选暴露文字和嵌套实例属性。
- 超级选择器可按选中容器的内在、直接子级或全部子孙范围筛选，并支持图层、样式、布局、文本、组件和原型等高级属性。
- 智能填充支持数字/时间按序填写，以及等差、等比、斐波那契、质数、平方、三角数和阶乘等数列。
- 文字工具默认在选中图层查找，支持结果全选与一键批量替换。
- 尺寸助手提供主流设备、常见屏幕和经典比例预设，支持批量尺寸、横竖切换、锁定比例与保持中心。
- 语言切换会稳定复用集合和模式，并保护占位符、变量、数字、换行和产品名。
- 查重支持整行同时定位两侧元素，并缓存最近一次结果。
- CompKit 提供精确矩阵、紧凑说明书预设和批量目录输出。

## 构建与验证

```bash
npm install
npm run verify
```

构建产物为 `code.js`。在 Figma 中导入本目录的 `manifest.json` 即可加载开发版本。

跨平台完整验证请在仓库根目录运行 `npm run verify`。

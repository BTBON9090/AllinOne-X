# All in One for Figma

这是 AllinoneX 4.1.0 的 Figma 实现，与同仓库 `../mastergo/` 版本同步维护。

## 主要能力

- 简易工具、超级选择、智能填充、文字工具、PPT、组件清洗、Jumpback、等轴形变、语言切换、CompKit 与跨画板查重。
- 实例逆向母版：从所选实例的当前状态创建新的本地母版，原实例保持不变；本地组件集最多完整还原 100 个真实变体。
- 组件构建器：把一个或多个 Frame 创建为单个组件、多个组件或组件集，可选暴露文字和嵌套实例属性。
- 超级选择器可按选中容器的内在、直接子级或全部子孙范围筛选。
- 智能填充自定义字段支持顺序与随机分配。
- 查重支持整行同时定位两侧元素，并缓存最近一次结果。
- CompKit 提供精确矩阵、紧凑说明书预设和批量目录输出。
- AI 组件规范优化支持命名、属性值、描述与组件异常反馈。

## 构建与验证

```bash
npm install
npm run verify
```

构建产物为 `code.js`。在 Figma 中导入本目录的 `manifest.json` 即可加载开发版本。

跨平台完整验证请在仓库根目录运行 `npm run verify`。
